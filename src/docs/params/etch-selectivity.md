## Physical meaning

Selectivity is represented as the target-material removal rate divided by the other-material removal rate. A larger ratio preserves non-target cells more strongly for the same nominal target removal, but the value is an input and is not calculated from chemistry or surface state.

## Failure modes

- Low selectivity can consume a mask or stop layer before the target clears.
- Treating an extremely high input as physically guaranteed can hide small but important non-target loss in a real process.
