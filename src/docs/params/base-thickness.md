## Physical meaning

This value sets the vertical size of a starting material layer in nanometres before any process step runs. The grid represents it in whole cells, so the visible thickness is quantized by the selected cell size rather than being a continuous film measurement.

## Failure modes

- A layer that is too thin can be completely consumed by an etch and expose the layer beneath it.
- A layer that is too thick can push other interfaces outside the visible grid or leave more material than the intended cross-section.
