## Physical meaning

Mandrel width is the geometric critical dimension of each sacrificial core before sidewall spacers remain. Changing it regenerates the periodic top-down mandrel polygons; manually dragged polygon edges can also define local width at a cut. It controls one of the two alternating free-space populations, so width error can appear as local placement error after frequency doubling even when spacer thickness is uniform.

## Failure modes

- Width bias can make the former-mandrel gap and the between-mandrel gap alternate in size.
- An extreme width can leave no room for a valid spacer/open-space construction at the chosen pitch.
